# ADR-0001: 单租户私有部署

## 状态
已接受

## 背景
本系统操作的内部 API 元数据、凭证、调用记录都属于企业机密。若采用多租户 SaaS,每个存储层(MongoDB collection / 索引、Milvus collection、凭证 vault 配额、审计日志分区)都需要租户隔离层,每个读取路径都需要租户感知的授权层。当前产品处于生命早期,典型客户为单一企业。

## 决策
系统以单租户方式交付。每个运行实例服务一个客户。所有存储、凭证、审计日志归该客户所有。

## 后果
- 认证/授权层不需要租户维度:业务人员身份即授权主体。
- Schema 迁移与容量规划按客户独立,不需全局协调。
- 未来将某客户迁入多租户 SaaS 时,需要重新分区所有存储 — 这是不可忽视的工作量,但比"第一天就上多租户"的成本低。
